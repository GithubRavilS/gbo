# Открыть сайт инвестору

**В Safari на Mac — открой эту ссылку:**

https://cdn.jsdelivr.net/gh/GithubRavilS/gbo@cursor/gbo-katerina-quote-bddf/index.html

Если страница старая (кэш), обнови через минуту или открой локально:

```bash
cd ~/Documents/Cursor/gbo
git fetch origin cursor/gbo-katerina-quote-bddf
git checkout cursor/gbo-katerina-quote-bddf
open -a Safari index.html
```
