# GBO поставка (PL → RU)

Расчёт поставки фильтров/редукторов AutoChill → Казань.

**Без двойной заморозки:** аванс → товар с аванса, касса = landed один раз.

## Открыть

- `index.html` — полный расклад (SKU / соло / компоновки / объёмы)
- `VARIANTS.md` — тот же ответ текстом
- `python3 build.py` — пересчёт
